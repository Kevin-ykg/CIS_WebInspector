## 离线实现边界

[独立脚本](run_offline.py) 使用冻结原尺寸 Alpha/CIS ROI，不调用生产 DLL，也不依据人工点求矩阵。固定目标矩形决定唯一工作尺度；二值结构图、空间均衡 SIFT、双向 ratio 匹配给出同一组匹配点；分别做相似与仿射 RANSAC；以几何范围、内点、九区模板边缘距离作质量检查；相似与仿射接近时选相似。矩阵仅来自 SIFT 对应点；轮廓不产生平移也不精修矩阵。最后才用人工点独立评价。当前冻结图像只有核心 ROI，没有更大的真实搜索上下文，因此本脚本并未验证“扩展裁图能找回原本被切掉的特征”。

**这仍是首轮原型，不是完整计划实现：** 尚未实现独立的竞争周期/多解复核、结构化 C ABI 状态、正式缺陷流水线汇总；这些项目不能因本轮原型运行成功而视为通过。

这里暂把用户所说“标注误差约 3px”理解为**每张图上单个点击点**的误差；若用户指的是一组 Alpha/CIS 配对坐标的总误差，则下述量级需要相应收紧。若再把 3px 暂作**每个点偏差不超过 3px**的假设，两个点击坐标形成一个配对时，由三角不等式可得约 `2×3=6px` 的最大标注差。用户给的是估计值而非经重复标注测出的硬上界，所以这里的 6px 只是**解释残差的近似量级**，不能从 `观察残差≤6px` 推出真实几何误差≤2px。结果 JSON 同时保留原始残差和 `max(0, 残差−6px)` 的乐观超额量，后者仅用于定位明显超出标注噪声的样本，不用作生产通过门槛。

## 已做验证与尚缺验证

- `python -m py_compile` 通过；8 件图像/87 点/3 框均可读取且坐标未越界。
- 相同进程重复运行 3b…，模型状态与原图矩阵逐值一致；给同一图像增加外层零像素并按固定目标矩形截回后，原像素与工作图逐像素一致。这是小范围确定性检查，**尚不是**冷/热缓存、处理顺序、并行度 1/4/8 的完整验收。
- 只标有 3 处外部缺陷，缺少带定位真值的内部/细线断裂病例，尚无法验收“三类真实缺陷不被对准抹掉”。
- Python 原型未复用生产 C++ worker/模板缓存，单件约 0.25～0.62s；这与生产日志不是同实现同条件对比，不能据此判断是否满足 `≤20%` 性能目标。
- 2b…平均改善却局部恶化、5b…内部过关却人工点很差，说明当前离线质量门控还需独立证据；不能为提升接受率而简单放宽局部退化限制。

## 下一步决策点

1. 用户已确认同名角点/尖端，估计单侧点击误差约 3px。若 `P95≤2px` 仍是硬性几何验收目标，应额外建立更高精度的小规模独立真值（重复独立标注唯一角点并测量分散度，或采用经人工复核的高精度基准）；当前 87 点可用于错周期/区域性偏移诊断，但不能单独认证 2px。
2. `img2/04200…` 顶部混入的二维码/相邻图案需给出目标归属或固定目标矩形；不能让算法按最大连通域自行猜。
3. 补入至少一件有定位真值的内部缺陷和一件细线断裂，完成缺陷保留验证。
4. 待真值精度与目标边界明确后，继续离线统一模型：重点解决稀疏目标和候选全件分区可靠性，再测固定裁框、顺序/并行一致性、错周期负例和同机耗时。未全部通过前不部署生产 DLL。
